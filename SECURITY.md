# Security Policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities in a public issue. Use GitHub's private vulnerability reporting feature for this repository when available. Include the affected version, reproduction steps, impact, and any suggested mitigation.

DSHBuddy stores configuration and companion data locally under `~/.petdex/`. Reports involving accidental exposure of API keys, conversations, or local paths are especially helpful.

Security fixes are prioritized for the latest published version.
